# EarlyYears Nexus

This repository contains two HTML files:

- `EarlyYears-Nexus-Website.html` — public-facing website / landing page.
- `EarlyYears-Nexus.html` — interactive platform dashboard prototype.

## Run locally

Open either HTML file in a modern browser. Both are self-contained HTML prototypes, with external Google Fonts loaded from Google Fonts.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Extract this ZIP and upload the two HTML files and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub Pages will publish the repository. The dashboard file can be opened at `/EarlyYears-Nexus.html`.

To make the landing page the default site at the repository root, rename `EarlyYears-Nexus-Website.html` to `index.html` before publishing.
